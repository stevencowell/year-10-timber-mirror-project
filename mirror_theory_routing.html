Theory Block 5

Routing and Profiles

A router can shape edges and cut rebates, but it must be used with care and control.

Key Idea

A router removes timber quickly, so control matters.

Students may use a router to create round-overs, chamfers or a rebate for the mirror. The bit must be secure, the timber must be controlled, and test cuts should be made on scrap first.

Why It Matters

Routing can improve the frame shape and make a rebate for the mirror, but mistakes happen quickly if the cut is too deep or the timber is not controlled.

Safe Routing Checklist

  • Wait for the teacher demonstration.
  • Check the bit and depth setting.
  • Use guards, fences and push blocks where required.
  • Keep hands clear of the cutter.
  • Make a test cut on scrap timber.
  • Do not start with the bit touching the timber.

Router Choices In The Mirror Project

Routing is used for both appearance and function. An edge profile changes how the frame looks and feels. A rebate creates the step that supports the mirror or backing board. Both jobs need test cuts because router depth, feed direction and timber grain can change the result quickly.

Router Job Purpose Quality Check
Round-over Softens a sharp edge and makes the frame more comfortable to handle. Profile is even, no burn marks, no tear-out at the end grain.
Chamfer Creates a clean angled edge and a sharper design style. Angle is consistent and corners meet neatly.
Rebate Creates a recess for mirror glass or backing board. Depth and width suit the mirror, with no weak thin edge left behind.
